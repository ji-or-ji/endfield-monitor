## 本版做了什么

### 环上的读数：CPU 与内存各归各位

圆环上那两个角标以前放的是「实际占用 / 最大占用」（都是综合值），现在改成各自贴近自己那条弧：

- **右上**（橘弧一侧）= CPU：`1.91 GHz` + `CPU`
- **左下**（蓝弧一侧）= 内存：`内存` + `11.2 GB`

圆心仍是综合占比 `58 / 100`，没动。

### 环上与底栏互补，不再重复

同一个读数不该出现两遍，所以两边**一正一反**：

| | 环上角标 | 底栏汇总 |
|---|---|---|
| 打开「环上显示具体数值」 | 实际数值（频率 / 已用 GB） | 百分比 |
| 关闭 | 百分比 | 实际数值（频率 / 已用÷总量） |

设置项也据此改名为「环上显示具体数值」，并补了说明。

### 电池：容量与健康度

- 启动时取一次满充容量与设计容量。Windows 走 `root\WMI` 的 `BatteryFullChargedCapacity` 与 `BatteryStaticData`（原生 WMI，不经过 PowerShell）；Linux 读 `energy_full(_design)`，退而求其次用 `charge_*` 乘电压折算
- 客户端：规格列显示满充容量；点开详情能看到满充容量 / 设计容量 / **健康度**

### 显卡：显存总量

- 改从显示适配器类注册表的 `HardwareInformation.qwMemorySize` 读（WMI 的 `AdapterRAM` 是 32 位，超过 4GB 会截断）
- 核显没有专用显存，读不到时明确写「核显或驱动未上报」，不编数字
- 有总量时，当前数据列给出「占用 / 总量」

### CPU：不再拿标称冒充「最高频率」

睿频上限在系统里没有可靠的标准接口（WMI 的 `MaxClockSpeed` 给的是标称，注册表的 `~MHz` 又是另一个口径）。所以：

- 规格那一栏改标「**基准** 2.10 GHz」
- 另报**运行中观测到的实时频率峰值**——它是真的，会随负载慢慢爬上去
