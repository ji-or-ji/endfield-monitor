## 本版做了什么

改动全部集中在**客户端**。

### 点云改用 GPU 批量绘制

原来每个点是一个独立的四边形路径，Skia 要在 CPU 上逐条细分 5500 条；现在每个点摊成 6 个顶点，整团**一次 `DrawVertices`** 交给 GPU。
设置里新增「点云批量绘制」开关，关掉即回退到老的逐点画法，方便排查。

顺带把抗锯齿打开了——之前为省开销关着，结果每个小四边形都是硬边像素块，看着像"实心、没透明度"。

### 窗口不在前台时自动降级

- 外圈不再画点云，改画与圆心同款、但更大的灰块（**外一圈、内一圈**）
- 刷新降到约 **7fps**；精简档直接画一帧定格
- 实测（20 秒均值，整机占用）：前台 8.0% → **失焦后约 1.0%**

> 说明：实测发现开销大头其实是"每秒 60 次重绘"本身，而不是画什么。所以失焦时不只换了形状，也把刷新降了下来，否则省不动。

### 界面不再整体滚动

去掉外层 `ScrollViewer`，内容按窗口尺寸自适应；圆环那块在窗口变矮时**整体等比缩小**，不会顶出布局。应用列表与设备列表各自内部滚动。

### 设置里可切换具体数值

CPU 显示实时频率、内存显示已用/总量；**圆心那个数字始终是综合占比**，两种模式下都不变。

### 其它

- 清掉两个过时 API 警告（`Bitmap.Save` / `TextBox.Watermark`）
- 服务器地址手填 `http://` 时会被拼成 `http://http://…` 的问题已修（自动剥离多余前缀与尾部斜杠）

## 附件说明

- **EndfieldMonitor-v0.2.0-win-x64.exe** — 客户端。C# + Avalonia，单文件、自带运行时，双击即用
- **enf-collector-v0.2.0-windows-amd64.exe** — 服务端（Windows）。本版未改服务端，内容与 v0.1.2 一致，重新构建以便版本对齐
- **enf-collector-v0.2.0-linux-amd64** — 服务端（Linux），尚未在真机验证
