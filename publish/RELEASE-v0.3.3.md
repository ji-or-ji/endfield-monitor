## 本版做了什么

### 采样分成两种模式，默认不变

主要模式（默认）跟以前一样：不管有没有人在看，都按 1 秒 / 2 秒固定节拍采。

轻量模式是这一版新加的开关，三种开法都一样：

```powershell
.\enf-collector.exe --lite
```
```json
{ "lite": true }
```
`--setup` 向导最后也会问一句。

打开之后，30 秒没人拉快照就把节奏放慢（进程 30 秒一次、其余 5 秒一次），
客户端一来立刻补采并把节奏拉回去，界面上看不出差别。切换时日志会打一行，
方便确认它当前在干什么。

实测（本机 i5-13420H，12 线程，停掉客户端后取 30 秒窗口）：

| 模式 | 整机占用 | 单核口径 |
| --- | --- | --- |
| 主要（默认） | 0.339% | 4.06% |
| 轻量·没人看 | 0.035% | 0.42% |

两种模式都保留的一项优化：网络计数改为直接查主网卡一个接口。
之前用的 gopsutil 会先枚举全部网卡（这台机器上几十块虚拟 / VPN / 隧道网卡）再逐块查一遍，
实测每次 10 ms；改成记住接口索引后是 0.82 ms。

### 客户端：应用列表显示进程路径

应用行在窗口标题下面多了一行小字，显示这个进程的可执行文件路径，整行悬停还能看到
PID 与完整路径。几个同名的 chrome / python / msedgewebview2 现在一眼能分清是哪个。

路径长了只留尾部（`…\目录\文件名`）：头部多半是 `C:\Program Files` 这类公共前缀，
尾部才是用来区分程序的，顺带也不会顶到右边的占用列。

顺手修掉一处重复：没有窗口标题时，副标题原本会回落成进程名，跟主标题一模一样。
