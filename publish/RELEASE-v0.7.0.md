# EndfieldMonitor v0.7.0

> **这一版不稳定，别当稳定版用。**
> 被控设备从"一个地址"改成了"一份设备列表"，界面、配置结构、连通状态都还在动，
> 后面的版本很可能继续改它们。想求稳的请留在 v0.6.x。

## 被控设备列表：多设备记录、连通探测与新建/编辑页

把"监视哪台"从设置窗里的一个地址栏，改成了一份真正的设备列表。

### 设备记录

- 每台记五项：**名称、描述、地址、端口、口令**，落在客户端 `config.json` 的 `devices` 里
- 地址与端口分开存。地址栏会自动剥掉 `http(s)://` 前缀与路径尾巴，误粘进来的
  `:端口` 会摘出来填进端口栏，不会拼成 `host:8898:8898`
- 校验：长得像 IP 的必须四段、每段 0-255，`22`、`191.981` 这类当场报错、**不写盘**
- 地址留空按"监视本机"处理，落成 `127.0.0.1`
- 老配置里的 `server` / `token` 仍照旧生效；`devices` 为空时就走老逻辑那一台

### 新增的页面

- **跨设备监控总览**（底栏「切换被控」进）：每台一条卡片，一台居中在 1/2，
  两台落在 1/3 与 2/3，三台及以上改滚动列表
- 点卡片把这个被控切过去；卡片右侧浅色药丸「编辑」弹出编辑卡，五栏可改
- 设备页右上角淡灰图标按钮进**新建被控**页，同样是那五栏
- 设置窗撤掉服务器地址与共享口令两栏，连接改由设备列表管理

### 连通状态

- 进总览页时对每台发一次 **800ms** 短超时探测；探不到的那张卡缓动置灰
  （0.7 秒、三次方缓出，不是一下子跳过去）
- 探测结果不会被每秒的刷新冲掉

### 主页面

- 左下角第一行改为「**名称 · 描述**」（描述为空就只留名称）
- 第二行仍是上次刷新时间；第三行还原为主机名与服务状态；第四行是三枚标签

### 这一版修掉的两处

- 切被控只改了配置、没把新地址交给正在跑的请求对象，于是界面写着 A、数据却来自另一台
- 每秒重建卡片把探测结果抹掉，连不上的设备一直亮着

## 已知不稳 / 还没做

- 设备列表与连通状态是全新的，行为还在改，配置结构也可能再动
- 探测只在进页面那一次跑，没有轮询：某台后来起来了，要重新进一次页面才变亮
- 「把配置交给客户端」这段逻辑散在三处（启动、切被控、改当前那台），还没收拢
- 「描述」目前只存着并显示在主页面那一行，别处还没用
- Linux 侧仍未在真实机器上验证（图标采集、启停、更新替换脚本、客户端界面）

## 下载

见本发行版附件。平台 win / linux，架构 x64 / arm64。
套件（bundle）里客户端与采集端同目录即可，客户端会自动拉起采集端。
